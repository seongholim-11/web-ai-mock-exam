# 웹·AI 모의평가

제공된 「모의고사 80문항」과 「정답과 해설」을 기반으로 만든 한국어 학습 웹페이지입니다.

- 종이 질감, 명조체, 2단 시험지와 반응형 답안지
- 80문항 4지선다, 100분 타이머, 자동 제출
- 답안·시간·이름·다시 볼 문항을 현재 브라우저에 저장
- 자동 채점, 영역별 점수, 문항별 해설, 오답·미응답 복습
- 모든 80문항의 시험지와 채점 후 해설 인쇄

## 실행

빌드가 필요 없는 HTML/CSS/JavaScript 정적 사이트입니다. `index.html`을 브라우저로 열거나 이 폴더에서 `python -m http.server 4173`을 실행하세요. 외부 글꼴이 연결되지 않으면 기기의 명조체로 표시됩니다.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → `main` / `(root)`를 선택하고 저장합니다.

## 데이터와 개인정보

응시 정보는 별도 서버에 전송되지 않으며 기기·브라우저마다 독립적입니다. 타이머는 응시 중 탭을 닫아도 흐르고, 일시 정지 버튼으로 멈출 수 있습니다. 새 시험은 기존 답안과 성적을 초기화합니다. 정적 학습 도구이므로 정답 데이터는 소스에서 확인할 수 있습니다. 감독형 평가에는 적합하지 않습니다.

문제와 해설의 내용 및 관련 학습 자료 링크는 사용자 제공 파일을 따릅니다. 실제 시험 문제·출제 비중을 보장하지 않습니다.
